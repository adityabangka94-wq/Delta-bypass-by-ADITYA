# Delta-bypass-by-ADITYA

Solver key Delta Executor — generate key otomatis dari link auth Platoboost tanpa nunggu iklan atau captcha manual.

---

## Apa Ini?

Tool Python buat generate **key Delta Executor** otomatis dari link `auth.platorelay.com/a?d=...`. Ambil link dari Delta app, jalanin script, key keluar. Selesai.

Cocok buat yang males nunggu iklan, captcha, atau klik satu-satu di halaman key.

---

## Requirements

- **Python 3.10+**
- **Termux** (Android) atau **Python** di PC/laptop
- **Library:**
  - `requests` — HTTP client
  - `urllib3` — disable SSL warning
  - `pycryptodome` — AES encryption
